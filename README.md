# 🏛️ Deep History Studio

> Faceless history-documentary series generator. You queue topics
> ("daily life in the Roman army", "what the first humans ate").
> Each run: researches REAL sources → writes a chaptered script →
> generates stick-figure-style illustrations → narrates in a chill voice →
> renders a vertical 720×1280 episode → delivers to Telegram.
> Runs free on GitHub Actions. OpsHub is notified on every episode.
